# localTextComparingTool
**TextDiff Pro Max** — A fully-featured local text comparison tool. <br>
Download `htmlfile.html`, open it in any browser, and compare texts — no installation or internet required.

## Features
- **Three view modes:** Side by Side · Unified · Inline
- **Word and character-level highlighting** within changed lines
- **Line numbers** on both sides in every view
- **Stats bar:** added / removed / changed / unchanged counts + similarity %
- **Navigate diffs** with ◀ ▶ buttons or keyboard (`N` / `Shift+N`)
- **Dark / Light theme** toggle (respects system preference, persists across sessions)
- **File input:** drag & drop files onto either pane, or use the file button
- **Paste from clipboard** and **JSON formatter** buttons
- **Options:** Ignore whitespace · Ignore case · Ignore blank lines · Configurable context lines · Line wrap
- **Collapsible unchanged sections** (click to expand)
- **Find in diff** — highlights matches without corrupting word-level diff marks
- **Copy diff** to clipboard or **download as `.patch`** file
- **Auto-compare** (debounced) + manual Compare button
- **Keyboard shortcuts:** `Ctrl+Enter`, `N`, `Shift+N`, `T`, `W`, `V`, `Ctrl+F`, `?`, `Esc`
- **No external dependencies** — works fully offline as a single HTML file
